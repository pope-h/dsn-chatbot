# DSN Chatbot (workshop starter)

This is the starting point for the hands-on workshop. Open **`WORKSHOP.md`** and follow it.

The finished version, with a few extras, is on the `main` branch.

```bash
npm install
cp .env.example .env.local     # paste your Gemini key in .env.local
npm run dev                    # http://localhost:3000
```
